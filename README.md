# VP Wedding World — GitHub Pages

This is the original self-contained VP Wedding World website updated into five navigable pages: Welcome, Venues, Map, Itinerary and Contact Us. All original embedded images and venue illustrations remain in `index.html`.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` from this ZIP to the repository root.
3. In Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. GitHub will provide the public Pages URL when deployment completes.

The Map page uses Leaflet/OpenStreetMap tiles and opens selected directions through a standard Google Maps directions link. Both require an internet connection.
